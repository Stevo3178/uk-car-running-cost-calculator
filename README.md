# UK Car Running Cost Calculator — Goldcrest Guides

A responsive, dependency-free website for estimating UK car running costs.

## Files
- `index.html` — complete calculator (HTML, CSS and JavaScript in one file).

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `uk-car-running-cost-calculator`).
2. Upload `index.html` and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then save.
6. Wait for the Pages deployment to finish. The public URL will appear in **Settings → Pages**.
7. Test the published URL on desktop and mobile before changing the button link in Payhip.

## Calculation notes
- Fuel cost uses UK imperial MPG and 4.54609 litres per imperial gallon.
- Annual running cost includes fuel, insurance, VED, servicing, repairs/tyres, MOT, parking/permits and other costs.
- Monthly finance is shown separately as an additional monthly cash outlay and is not included in the per-mile running cost.
- Results are estimates, not financial advice; users should enter their own current figures.
